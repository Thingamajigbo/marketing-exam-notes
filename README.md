# 마케팅원론 시험 정리 노트

마케팅원론 1–4장의 핵심 개념과 OX·단답·사례 100문제를 담은 정적 HTML 학습 노트입니다.

- 핵심 개념과 비교표, 시험 직전 압축 정리
- OX 자동 채점, 단답·사례 자기 채점, 오답 복습
- 검색, 브라우저 내 학습기록 저장, 인쇄 지원
- 외부 라이브러리 없이 동작하는 단일 HTML

학습 기록은 브라우저의 localStorage에 저장되며 서버로 전송되지 않습니다.

## 사이트

## 배포

GitHub Pages에서 `main` 브랜치 루트의 `index.html`을 제공합니다.

강의자료를 바탕으로 재구성한 학습용 노트이며, 연습문제는 실제 기출문제가 아닙니다. 원본 PDF·PPTX는 저장소에 포함하지 않습니다.
